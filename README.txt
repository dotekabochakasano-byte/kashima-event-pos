鹿嶋まつり イベントレジ Ver.0.4

追加内容:
- 支払方法ボタンの選択状態を強く表示
- 「選択中：現金 / PayPay / 楽天ペイ / d払い / au PAY / クレジットカード」を常時表示
- 精算完了時に日別の受付番号を表示
- 「受け渡し」画面を追加
- 精算済み注文を受付番号ごとに一覧表示
- 商品ごとの受け渡しチェック
- 全商品チェックで「受け渡し完了」
- 未完了のみ / すべて の切替
- CSVに受付番号・商品受渡済・注文受渡完了を追加

既存のIndexedDBを使うため、同じURL/オリジンで開けば商品・売上データは引き継がれます。


Ver.0.5: 現金会計の会計完了判定を修正。iPad標準キーボードを使わない専用お預かり金テンキーを追加。


Ver.0.6: iPad/Safariで現金会計ボタンが押せない場合に備え、ネイティブdisabledを廃止し、会計可否をアプリ側で判定する方式に変更。会計状態メッセージを追加。

Ver.0.7: iPadのHTTPローカル接続でcrypto.randomUUIDが利用できない場合の会計保存不具合を修正。


Ver.0.8: iPad/Safari向け会計ボタンのタップ処理を強化。inline onclick / pointerup / touchend / capture fallbackを追加し、処理開始表示とエラーalertを追加。


Ver.0.9: iPadでの「更新」ボタン反応を強化。上部「受け渡し」と精算完了ダイアログの「受け渡し画面へ」は、ページ下部の受け渡し確認欄までスクロールする仕様に変更。

Ver.0.11: 売上修正画面で同額商品の追加・入替に対応。CSV会計IDを kashima-mYYYYMMDD-受付番号 形式に簡略化。内部DBの一意IDは変更しない。


Ver.0.12: 完全オフライン時の不要なネットワーク要求を抑制。商品管理に並び順を明示し、↑↓で手動並び替え、カテゴリー順（フード→ドリンク→ジェラート→その他）の一括整列を追加。


Ver.0.13: レジの商品グリッドをカテゴリー単位で行揃え。ドリンクは1行2商品＋右端空白で配置し、フード6品・ジェラート3品は3列で表示。


Ver.0.14: レジ画面のカテゴリー表示順をフード→ドリンク→ジェラート→その他に固定。ドリンクは2商品＋右端空白の2列運用を強制。画面上部にバージョン表示を追加。


Ver.0.15: 商品管理の各カテゴリーに『＋ 空白』を追加。空白マスを商品と同じように↑↓で移動・削除でき、任意の位置に空白を作れるように変更。画面上部にバージョン表示を追加。

Ver.0.16: 商品管理の『＋ 空白』を全カテゴリーで表示。↑↓・編集・停止・空白追加/削除時に商品管理ダイアログが閉じないよう、ボタンのform送信を抑止。ヘッダーにVer.0.16を表示。Service Workerのキャッシュ対象もv16へ統一。

Ver.0.17 追加機能
- 顧客表示専用画面 customer.html を追加。
- レジ画面の「顧客表示」ボタンから別ウインドウで開けます。
- 同一iPad内で注文内容・合計・支払方法をリアルタイム連動（BroadcastChannel＋localStorageフォールバック）。
- 会計完了時は受付番号と支払内容を約6.5秒表示し、その後広告待機画面へ戻ります。
- 商品管理内に「顧客表示・広告設定」を追加。MP4等の広告動画をiPad内IndexedDBに保存・差し替え・削除できます。
- 広告動画未設定時は鹿嶋まつりの待機画面を表示します。
- 外部モニターでは、iPadOSのStage Manager等を使って顧客表示ウインドウを外部画面へ移してください。
- 動画は自動再生の安定性のためミュート・ループ再生です。推奨形式はH.264のMP4です。
